每台设备上

Jarvis 是一个大脑加四个身体。大脑是家里树莓派上的一个 Python 进程，它管记忆、事件日志、模型调用和工具。iPhone、Apple Watch、iPad 和 Mac 只通过 Tailscale 连到它（ADR 0170）。

每个身体都自带麦克风、唤醒词、回声消除和扬声器，因为声音必须在听到它的地方处理。密钥和这一轮的决策留在大脑里。这样分工，所以新增一台设备是多一个身体，而不是多一份 Jarvis。身边有好几台设备时只有一台回答，见和它说话。

iPhone

Section titled “iPhone”

手机有三个页面：Today、Chat 和 Map。它也感知你生活的大部分：位置、运动、健康数据，以及在前台的 App。按操作按钮、App 打开时喊“Hey Jarvis”，或者从别的 App 把东西分享给它，都可以。

Apple Watch

Section titled “Apple Watch”

点一下就说，答案在手腕上看。提醒、“该出发了”和公交进度会以卡片的形式出现。手表没有自己的令牌，也没有自己的连接：它和手机说话，手机再和大脑说话，所以从手表开始的一轮会被标明，并以文字回答。手机不在身边时，手表显示它最后一次收到的那一天。

iPad

Section titled “iPad”

同样的一天和对话，放在更大的屏幕上，另外还有 Jarvis Remote：把 Mac 的屏幕放到 iPad 上，最高 120 fps，用触摸、触控板手势和语音来操作。Mac 上有一个它自己的小 App，用 ScreenCaptureKit 抓取屏幕，用 VideoToolbox 编码成 HEVC。它只接受来自 tailnet 和本机的连接，要配对令牌，也不经过大脑。

iPad 自己什么都不感知。在非手机设备上，App 不启动任何采集，也不记录任何东西，所以 Jarvis 对你这一天的了解，来自随身带着的设备。

Mac

Section titled “Mac”

在 Mac 上，Jarvis 是刘海旁边一个带眼睛的玻璃小球。它被设计成瞥一眼就够：不用打开什么，也不压在你的工作上。

  • 它是活的。 它会眨眼、跟着你的指针转，大约十分钟你都没动指针，它就打盹。它只有一个：指针停到另一块显示器上，它就搬过去。没有刘海的屏幕上，它待在顶部居中的黑色药丸里。
  • 它有皮肤。 按住它一会儿，它就换一身外观。
  • 点一下，或双击 ⌘，是一回事。 开启一段语音对话，打断它说到一半的话，或者结束对话。
  • 它告诉你什么需要你。 你的编程助手（Claude Code 和 Codex 会话）或这一天的时间线，会显示在刘海旁边。助手要运行命令时，刘海上会落下一张卡片，你在那里允许或拒绝。
  • 它记录屏幕上的活动，作为这一天的记录，需要你先授权。

它宁可安静

Section titled “它宁可安静”

能打扰你的只有刘海上的卡片，而每张卡片都带一小行，问你这个音量对不对。你的回答连同卡片的快照（种类、标题、安静级别和钟点）留在你自己的机器上，不会留下助手写的内容或命令。目前评分只是记录，还没有拿来学习：决定卡片级别的规则是固定的，这份日志让更好的规则可以拿来对比测试。

安静是大脑持有的一个级别，所以刘海、提示音和声音保持一致，重启后也还在。每一级都包含前一级：

  • 安静： 它不会主动开口，提示音全关，卡片仍然显示。
  • 不弹窗： 连卡片也不出。
  • 勿扰： 外界的任何事都没有可见的反应。

被压下的东西不会丢。离开安静级别时，等着的事会合成一张卡片，“你不在时发生了 N 件事”，需要你的排在最前。你自己设的提醒在每一级都会响。
