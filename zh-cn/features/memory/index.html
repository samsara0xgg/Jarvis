它怎么认识你

Jarvis 对你的了解是纯文本，你能读、能改、能撤回。它靠一个循环建立起来：记录你的日子，问你的人生，每晚重写记忆，接受你的纠正。

它记录什么

Section titled “它记录什么”

它记下的一切都保持原样，从不覆盖。后面的步骤读这些记录，但从不取代它们。

  • 你去过哪里。 iPhone 在你移动时的每个 GPS 定位，以及你坐车时车的动作。
  • 你在做什么。 Mac 的屏幕活动，iPhone 和 iPad 上排在前台的 App，日历、邮件、消息、照片（只有元数据）、Safari 历史和 git 提交。
  • 你的身体。 来自 Apple 健康的睡眠、步数、运动和心率。
  • 你的话。 和 Jarvis 的每一次对话；如果你打开，还有 Mac 或手机录下的当天音频。
  • 你和编程助手的工作。 每一份会话记录，原样存在大脑上。
  • 你从别的服务导出的数据。 比如你的 claude.ai 历史，或一份银行账单。它们进入同一条时间线。

没有你的授权，什么都不读：每个来源都要在它所在的设备上单独授权。

来源会悄悄坏掉。有一天，Mac 的麦克风在睡眠之后停止录音，整整 36 小时什么都没送来；屏幕文字也有大约一天都在失败。所以夜里有一次检查，按「它本该产出的时间」而不是按钟点来看每个来源：Mac 一天大半时间在睡眠或锁屏，只有来源本该工作的时候，沉默才算数。一个来源安静下来，Jarvis 会出一张卡片，写明它的名字和最后一次送来数据的时间，数据恢复后卡片自动关掉。

人生访谈

Section titled “人生访谈”

它对你的记忆，从一场漫长、不赶时间的谈话开始：从小到现在你的故事，身边的人，你希望一个月后、一年后、五年后在哪里，以及你希望被怎样对待。它一章一章地来，一次问一个问题，问的是为什么、当时什么感受，而不只是发生了什么。这样它才能了解传感器看不到的东西。

它不会硬推。你还没准备好的一章，会等到你自己提起；你拒绝的话题，不会再问。你的回答一字不改地保存。只有你确认过的事实才进入记忆；Jarvis 自己推出来的东西，会标成猜测，下面说的每月重写只在现在有你自己的话作依据时，才会保留一条猜测。访谈的条目进来时是钉住的，标明是你自己的话，附上你说的那一天。夜里的整理可以建议某条已经过时，但只有你能删掉它。

每晚的重写

Section titled “每晚的重写”

每天夜里，Opus 根据刚过去的这一天重写这份记忆。记忆分十栏，每栏有固定的大小：

栏目 字数上限
经历 4,000
性格和价值观 3,000
身体 2,000
钱 2,000
兴趣和品味 2,000
你希望被怎么对待 3,000
定下来的规矩 3,000
证件和硬期限（只记日期，不记证件号） 1,000
身边的人 10,000
生活里的几件事 10,000

各栏加起来是 40,000 字的总上限。整份记忆每次对话都要带上，所以这些大小是一道关口：只要哪一栏超了，这一晚的整个回答就被拒绝，再问一次。它不会在显示时才截断，因为截断会让页面上还看得到的内容被提示词漏掉。大小这么紧，每晚就只能合并、提炼、舍得放手，而不是越写越长。

没有任何东西是原地修改的。每次改动都是一个新版本，旧版本都留着，每处改动都引用它出自你的哪几句对话。没有引用的改动进不来，哪一晚整理得不好，也可以在 Memory 页面整个撤回。一行被改写时，它早先的写法会连同当时有效的日子留在这一条上，所以记忆写下「你现在怎样」之后，「你当时怎样」仍然读得到。

哪些留下，哪些结束

Section titled “哪些留下，哪些结束”

这十栏里有两种内容。「你是谁」（经历、价值观、身体、兴趣和品味、身边的人、你希望被怎么对待）在有证据说它变了之前一直成立，沉默不会让它退场。「正在发生什么」（找工作、订车）只在它还活着的时候成立。

每件事带着一个状态，和最近一次证据的日子。有证据时它就关掉；或者程序发现它提到的、写下时还在后面的日期都过了，也会关掉。一件事 21 天没有证据，也不是直接扔掉：Jarvis 先去你的邮件、日历和记录里找，查不到才会问你一次，它是不是还在继续。关掉的内容不再进入提示词，但留在库里，能搜、能放回来。

每个月，模型可以根据当前版本和这个月的日摘要，把整份笔记重写一遍。只有每道检查都通过，它才会落成一个版本：每条钉住的内容一字不差地保留，每条被去掉的内容列出理由，大小也守住。Memory 页面会先显示改动，撤回和别的版本一样可用。第一次重写是手动跑的，看过之后才落，每月的自动重写在那之后才开始。

这一天本身会留成一份简短的摘要，对话的话题则从当天的原话重新建立，从不根据「摘要的摘要」。

你的纠正说了算

Section titled “你的纠正说了算”

在 Memory 页面打开任何一行，会看到它出自哪几句话。你可以确认、编辑、挪到别处，或者删掉。每个操作都是一个新版本，所以都能撤回。如果之后又有改动碰过同一行，撤回会被拒绝并指出是哪一行，而不是去猜你的意思。

你编辑或挪动过的行会被钉住。夜里的整理会丢掉它自己对那一行的重写，如果那一行看起来过时了，它只会给你留一个提醒。确认一行不会钉住它，所以它仍然能跟着你生活的变化更新。一次修改如果被第二天夜里悄悄盖掉，还不如没改。

为什么不把它训练进模型

Section titled “为什么不把它训练进模型”

这份记忆是文本，不是权重。它没有被训练进任何模型，所以更好的模型可以读同一份记忆，从第一天起就了解你。模型会越来越好，人人都会有；而你活过的日子，事后补不回来。这也是记录要从现在开始的原因。
