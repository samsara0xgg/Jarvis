# 报告格式

## `report_daily_work` 各字段

- `summary`：核心摘要，三句：这一天的主线是什么；有实证的完成项是什么（点名提交或
  Allen 的原话）；主要没做完或没证据的是什么。语音助手之后只读这一段和运行时附在
  它后面的按状态分组清单，所以这里不写没有依据的"完成"。
- `items`：按工作事项归并，同一件事的多次活动合成一项。每项：
  - `title`：事项名（不超过 60 字）。
  - `activity`：做了什么、产出了什么、进展到哪一步；写事实，不写评价。每个关键事实
    带上它的来源写法，见下。
  - `progress`：这一项的进展，按部分分开，每条一个部分：
    - `part`：部分名，如 代码、测试、部署、合并、申请；事项只有一个部分时为 null。
    - `status`：`browsed` 浏览 / `discussed` 讨论 / `attempted` 尝试或进行中 /
      `completed` 完成。`completed` 只用于这个部分的产物已经存在——当天的提交、发出的
      申请、Allen 本人说做完了——并且这条的 `refs` 引用了那条提交或那条原话。
    - `refs`：支撑这个部分的材料键。

    一件事同时有开发、测试、部署时分成几条，各自定状态：代码有当天提交就是
    `completed`；「部署」「上线」「常驻」「重启」「合并到 main」「测试通过」只有代理
    自述或屏幕文字时是 `attempted`，提交本身不是它发生了的证据。不要因为部署没证据
    就把有提交的代码也写成 `attempted`，也不要用一个 `completed` 盖住没证据的部署。
- `decisions`：重要决定和方案变化。`rationale` 只在材料里有依据时填，否则为 null。
- `open_items`：未完成事项、阻碍、待确认的问题。
- `user_next_steps`：Allen 明确表达过的下一步，必须引用他本人的记录键。
- `suggestions`：你根据材料提出的建议，和 Allen 的承诺分开。
- `uncertainties`：不确定之处、证据冲突、材料缺口。

## 正文里的来源写法

正文陈述一个事实时，把来源写进句子，让只读正文的人也能分辨：

- 提交：`提交 e17fbd2（当天，已在 main）` / `提交 53a8e97（当天，未进 main）`。
- Allen 的原话：`Allen 说……（r3）`。
- 代理（Codex、Claude 等）在终端或会话里的自述：`据 Codex 自述，979 项测试通过（未核）`。
  "验收通过""已合并""已部署""已重启""已修好"这类话只有代理自述或屏幕文字时，事项
  状态是 `attempted`，不是 `completed`。
- 屏幕上看到的：`屏幕显示……`。

## 保存的报告版式（由运行时组装）

```
# 工作日报 <日期>（<时区>）
生成时间、证据窗口、模型

## 核心摘要
<你的 summary>
完成（有当天提交或 Allen 原话）：1 <事项>、2 <事项>（代码完成，部署进行中）、…
完成（无当天提交或 Allen 原话）：…
另有进行中 N 项、讨论 N 项、浏览 N 项，见工作事项。
## 工作事项
### 1. <事项> — <状态>［依据：当天提交 e17fbd2；Allen 原话 r3］
<活动与进展>
引用：<来源引用>
### 2. <事项> — 代码：完成［依据：当天提交 bffe9d8］；部署：尝试/进行中［依据：仅 Codex 会话自述］
## 重要决定与方案变化
## 未完成、阻碍与待确认
## 用户明确表达的下一步
## 建议（模型提出，非用户承诺）
## 数据覆盖与不确定性
## 证据引用
```

每个部分后面的方括号由运行时按那条的 `refs` 自动写出：它点名这个部分引用了哪些当天
提交、哪些 Allen 的原话；都没有时写"仅屏幕/应用记录"或"无有效引用"。它不表示来源
支持这条结论，也不改写你填的 `status`；引用一个和事项无关的提交，方括号会把这个提交
原样写出来，读者一眼就能看出不对。标为完成却没有当天提交或 Allen 原话的部分，运行时
会在"数据覆盖与不确定性"里按事项编号和部分名点名。核心摘要里混合事项只列一次，标题
后面跟每个部分的状态。

`user_next_steps` 里引用不到 Allen 原话的条目会从该节移除，并在不确定性里原文点名。

引用按编号写在正文（`引用：#3, #7`），完整来源在报告末尾的"证据引用"里逐个列出。

报告超出正文预算时返回失败并保留旧版本，不截断正文或证据索引后保存。
