整合版One window: the long exposure decides where you go, the workbench decides what is at hand when you get there

长曝光管「去哪」，工作台管「到了以后手边有什么」。这一版把两页合成一个窗口，经典模式不要了，会话列表并进长曝光右边那一列名字。你发来的几个痛点也在里面：步骤只露正在跑的那一步，消息下面一排安静的图标，图片看得出是图、点得开，额度先回答够不够用。下面的窗口是能用的：点一下它，再按键盘。

01 · One window

一个窗口，一张键位表

两套窗口并存时，排序、状态词、键位都各说各的：同一个出错的会话，标题栏写「出错了」，长曝光的行上写「停了」；⌥↑ 在一边是上一个会话，在另一边是盖下长曝光。整合版只留长曝光这一套，地平线和她一直在最上面，← 永远是「退一层，看得更全」。

← 退一层·舞台 ← 对话（含并排）← 长曝光盖下来·只在输入框空着时生效，打字时 ← 还是移光标

从长曝光留下的地平线上的星星和她；← 盖下长曝光，行按开始时间排，状态变了行不挪；盖下来先停在名字上，↑↓ 换会话，→ 进去，← 回到你说过的话（main 3aa0949 的新走法）；她只在你停下来时开口；空格过一遍她手里的事。
从工作台拿来的三种姿态：对话、并排、舞台，卡片原地长成舞台那一下；七步落地和输入框上的小胶囊；终端的三个页签；输入框里的额度圆环。
新加的名字那一列就是会话列表：悬停出现置顶、放一边、改名、归档，最后是「＋ 新会话」「还有 N 个在歇着」「已归档」；⌘K 在长曝光里搜；眼前会话的批准回到对话里；切走时她和星星落进刘海，回来时一句汇报；Esc 有固定的顺序。
去掉的经典模式、它的侧栏和分组列表；右上角的上下文圈，并进额度圆环；标题栏上悬停才出现的按钮，换成一直看得见的 ⋯；终端「输入框里」那个位置，按你给工作台的话，默认并排，可换抽屉、浮岛。

02 · Steps

步骤：只露正在跑的那一步

跑的时候你想知道三件事：它现在在干嘛，干了多少，有没有出错。所以默认是一张卡，高度不变：它最后说的那句话，正在跑的那一步，一行计数和计时。点这张卡才展开全部。上面窗口里正在跑的就是这张卡。

正在跑的那一步

  • 看得出在跑。命令上一道光慢慢扫过，行尾是转圈和这一步自己的秒数（4s、1:02），不是 ✓。等得久的那一步，秒数一直在走，你知道它没卡住。
  • 跑完原地收尾。转圈变成 ✓ 或 ✕，结果（111/111、412 行）淡进来，停一下，再换下一步。
  • 换的时候像翻一页。旧的一行往上退出，新的从下面升上来；这一行高度不变，下面的回答一动不动。

太快的时候，和展开以后

  • 比眼睛快的步骤，卡上跳过。每一步至少露 0.56 秒，这期间来的只记最新的一步，到点直接换过去。计数和展开的列表一条不少。
  • 按它说的话分组。每组是它说完一句之后干的那几步。最新一组开着，早的每组一行；最多 300 像素高，里面自己滚，往上翻时出现「跟最新」。
  • 跑完收成一行。「✓ 干了 9 分钟 · 读了 4 个 · 改了 5 个 · 跑了 6 条 · 失败 1」，点开和上面一样。
在跑类型字（跑、读、改、搜、用）变亮；命令上一道光，1.9 秒扫一次；行尾转圈，加这一步的秒数

换下一步旧行 280 ms 往上退出（缓入）；新行晚 60 ms，380 ms 从下面升上来（缓出）；上下边各 4 像素渐隐，滑动时边缘是软的

03 · Message actions

消息下面：一排安静的图标

学 Claude：时间和几个 16 像素的图标排成一行，在消息自己的格子里。最后一条回答一直露着，别的悬停才出现；每个图标悬停 0.2 秒说出自己是什么，有快捷键的连键帽一起说。

回答时间 · 复制 · 引用 · ⋯（复制为 Markdown、从这里分叉）
你说的复制 · 改了重发 · 时间。改了重发是从这一句分叉出一个新会话，原来的不动
代码块右上角自己的复制，悬停出现
复制之后图标变成对勾 1.5 秒；剪贴板被拒时把文字选好，提示按 ⌘C

以前为什么被切掉：.item 用了 content-visibility:auto，它会裁掉画出格子的东西，而复制键用负边距 margin:6px 0 -8px -7px 伸出了格子。e39c9a2 已经把它改成格子里的图标加时间；整合版在这上面加了引用、⋯ 和你那一侧的操作。

05 · Usage

额度：先回答够不够用

点圆环时你想问的是一句话：还够不够用，会不会在这件事干完之前用完。所以第一行就是答案，够用、偏快、用完了，第二行一句话说为什么，数字在下面。演示窗口下面的「额度」三档可以切着看。

数字怎么读

  • 每条额度一根时间竖线。竖线是这段时间走到哪了：条没过竖线，就是用得比时间慢，重置前用不完。过了，第一句直接说「照这个速度，大约多久后用完」。
  • 每周的两条共用一个重置时间，写在组标题上，不再每行重复一遍。5 小时那条写还有多久、几点重置。
  • 上下文收成一行。这个会话用了多少、占 1M 的几成。「都占了什么」点开才出现分色条：它画的是用掉的这部分，不是整个 1M，所以 3% 的时候也看得清。

什么时候出声

  • 颜色只在不够时出现。够用是一个安静的圆环；偏快时圆环变暖，右上一个小点；用完变红，输入框上面一条横幅。
  • 按钮跟着状态走。平时只有右下角一个「看明细 ↗」；偏快时给「这个会话换成 Sonnet 5.5」；用完时才出现显眼的「挪到云端继续」。
  • 从圆环上长出来。卡片底下一个小尖角指着圆环；打开时三根条从左往右长一次，之后不动。

和现在的区别：现在的卡片把上下文、三条额度、看明细排成一样重的四块：答案要你自己比出来，「周二 5:00 重置」写了两遍，上下文那条在 3% 时只剩几个彩点，「看明细」是最大的按钮。数据不用加：竖线和「偏快」都从现有的 percent 和 resets_at 算，窗口多长看 key（five_hour 5 小时，seven_day 7 天）；改的是 workbench/usage.ts 的 card() 和 ring()。

07 · What changes

要改的：相对 main d73d6ca

先做完能用，再做顺手。改之前再看一眼 main，它这几天动得很快。

  1. 去掉经典模式。删「原模式」按钮和 setMode，侧栏和分组列表一起去；ADR 0081 和 spec §15.4 里「经典模式保留可选」那句一起改。
  2. 名字那一列当会话列表。行悬停出现置顶、放一边、改名、归档；最后三行「＋ 新会话」「还有 N 个在歇着」「已归档 N」。放一边的直接折进「在歇着」，不等一小时。
  3. 状态词只有一套。出错了 / 停了（你手动停的）/ 在整理 / 等你 / 在干活 / 做完了 / 看过了；标题栏和行上用同一个函数。
  4. ⌘↑ ⌘↓ 按长曝光的行序换会话。现在按经典列表的分组顺序，那个顺序看不见。
  5. 步骤卡。跑的时候一张卡：最后一句话、正在跑的那一步（转圈、扫光、这一步的秒数）、计数和计时；跑完原地变 ✓，停一下再翻到下一步，太快的只留最新的。展开后按它说的话分组，最多 300 像素，里面滚，有「跟最新」；展开时卡上那一步收起来，不显示两遍。改 renderSteps 和 .steps，ok 没来就是在跑，at 是它开始的时间；动画的时间照第 02 节的表。
  6. 额度卡。第一行答案（够用、偏快、用完了）加一句话；三条额度各加时间竖线，每周两条共用重置时间；上下文收成一行，点开才分色；看明细变链接，按钮跟着状态走。圆环画最紧的一项，偏快变暖。
  7. 消息操作。回答加引用和 ⋯，你的消息加复制和改了重发；图标 16 像素，点击区 28 像素，都在格子里。
  8. 图片。步骤里的截图和读的 png 也过 picHTML，答案里的图照样显示；现在的大图是只放一张的 .viewer，换成 Quick Look：左右翻、1:1、复制、在访达中显示，要宽度再放上舞台。
  9. 眼前会话的批准回到对话里。去掉键盘处理里 !attention.enabled 那个条件，⏎ / esc / 1–9 在没打字时生效；按下就锁住，卡片变成一行记录。
  10. 她手里「做完了」那张。⏎ 知道了（标为看过，下一张），L 收尾，⌘⏎ 先看看。连按 ⏎ 批权限时，不会一路按进 main。
  11. Esc 和 ← 只有一处代码管。顺序按第 06 节，舞台、并排、长曝光、她手里都在同一张表里；加 0.5 秒保护：刚关掉一层，紧跟着那一下不算打断。
  12. ⌘⏎ 只在出现「要落地吗」或落地面板开着时生效。现在输入框空着按就落地；她手里的 ⌘⏎ 仍是「去看全文」，两边不打架。
  13. 终端里跑 ! 开头的一行。在输入框里打 !npm test，它进终端跑，不进对话。
  14. 长曝光盖在上面，不再把对话往下挤。现在 .bw-desk 的 top 跟着 --sky 走；盖在上面，舞台和并排就不用跟着重排。
  15. 性能。长曝光只拉看得见的行的记录；holding() 只在数据变了时算一次，不在每一帧里扫全部记录。
