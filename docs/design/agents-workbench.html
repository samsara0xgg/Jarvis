工作台Around the conversation: a stage for what you look at, a line for what you land

长曝光管的是「去哪」，这一页管「到了以后手边有什么」。窗口只有三种姿态：平时是对话；看 diff、文档、终端时，旁边拉出一个面板，是并排；打开 artifact、网页、PDF 这类要宽度的东西，它占住大半个窗口，对话收成右边一条窄栏，是舞台。左边是落地：提交、合入、重启、推送，一键走到底，看得见每一步，随时能打断。

01 · Postures

三种姿态，按内容自动换

不做一堆可以随便拖的面板。拖出来的布局每次都不一样，眼睛每次都要重新找。窗口只有三种样子，由你打开的东西决定；地平线一直在最上面，右上角永远是会话，右下角永远是你说话的地方。

← 永远是「退一层，看得更全」·舞台 ← 对话 ← 长曝光盖下来 · 只在输入框空着时生效，打字时 ← 还是移光标

02 · Stage

要宽度的给宽度，对话让出来

网页和 artifact 是按宽度排版的，挤窄了就走样；对话是一栏文字，收到 372px 照样能读。所以打开这类东西时自动进舞台。进去的那一下是整页唯一「重」的动作：你点的那张卡片原地长大，变成舞台，同时对话往右收；退出时它缩回那张卡片，你回到原来那一行。

Artifact、网页、PDF、图片自动进舞台 ← / esc 退出
Markdown、spec、ADR、diff并排。右上角 ⤢ 可以推上舞台，也可以从舞台放回并排
终端和日志不进舞台，按你选的位置出现（第 04 节）
舞台里的对话只留最近一轮和输入框，更早的收成一行「更早 3 轮」，点开或往上滚就回来。窄栏里工具条只留图标
舞台里的落地面板收成 52px 的一条，只剩七个状态点；点它展开，舞台让一点
记住你的习惯某一类东西你连着三次一进舞台就退出，以后它就先并排打开

03 · Landing

落地：一条线，走到底，看得见，停得下

这不是一个通用的 Git 面板，是把 docs/git-guide.md §3 画出来：改动、门禁、提交、合入、重启、推送、清理。按一下走到底，背后调的是你的 commit skill，所以只提交明确的路径、不绕过 hook、提交信息的格式这些规矩都照旧。

看得见

  • 面板关着也看得见。跑的时候，输入框工具条上有一个小胶囊：「落地 · 门禁 2/7」。等你点头时变暖色，出错变红，做完变绿后几秒淡掉。
  • 每一步写清楚在干嘛。门禁一项一项亮；提交标题可以在跑之前改；重启会写出它判断的是 daemon 还是 companion。
  • 推送等你点头。和现在一样，git push origin main 的权限确认就是你的点头。

停得下

  • esc 或「打断」随时按。正在跑的这一步跑完才停，不会停在合入或推送的半中间；停下后可以「继续」或「留在分支上」。
  • 门禁红了自己停。写出哪一项、为什么，两个出口：「让 Claude 修」或「留在分支上」。和 CLAUDE.md 里「只在红色门禁、解不开的冲突时停」一致。
  • 合入冲突也停。机械能解的它解；要判断的，它停下来把两边摆给你。

04 · Terminal

终端放哪：四个位置，都在上面能试

终端和预览用同一块玻璃、同一套字体和颜色：成功是薄荷绿，等你是暖色，出错是珊瑚红，没有一块突然出现的黑框。三个页签：终端、服务（daemon 和 companion 的状态和重启）、日志。⌃` 开关。

我的建议是抽屉做「家」，同时允许在输入框里用 ! 开头跑一次性命令，结果就在输入框上方长出来，跑完一会儿自己收起。

05 · Composer

输入框：学 Claude 的克制，再多做一点

从 Claude 学的

  • 额度只有一个圆环。上下文、5 小时、每周、各个模型、云端余额，全在点开的卡片里。圆环画的是最紧的那一项，平时安静，快到了才变色。
  • 一行工具，都不抢眼。＋、模式、模型，都是图标加一两个字。

多做的

  • 额度用完不再是一大块红框。它缩成输入框里的一行，直接给出路：「挪到云端继续」。
  • 提示跟着状态变。输入框空着时右边写着 ← 现在会做什么：「长曝光」，在舞台里是「退出舞台」。
  • 落地的状态住在工具条里。不用开面板也知道走到哪一步。
  • 模型和强度合成一个。「Opus 5.5 · Max」，窄栏里只剩一个字。

06 · Decisions

要你定

  1. 终端的家放哪？四个位置上面都能试。抽屉最像 IDE，输入框里最轻。推荐：抽屉做家，! 命令在输入框里
  2. 落地的打断，停在哪？现在是「这一步跑完再停」，不会半途中断 git。门禁这种可以立刻杀掉的，要不要立刻停？推荐：门禁立刻停，其余跑完这步
  3. 「记住习惯」要不要？某类东西你总是一进舞台就退，以后先并排开。省事，但窗口会变得不那么可预期。推荐：要，并在舞台角上写一句「上次你放在旁边」
