asserts (g): a `refutes` reviewer evidence row (verdict=fail). Observed:

- diff artifact 9,731 chars — far under `_DIFF_TEXT_CHAR_CAP=50_000`, no

  get/set/delete/keys, tests cover basic behavior and 64-thread concurrency,
  stdlib-trace coverage check exercises kvstore.py" — everything it cites is
