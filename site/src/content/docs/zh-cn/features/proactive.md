Jarvis 宁可安静，也不愿打断你。真有事找你，会在刘海上出一张卡片，而每张卡片都让你说一句：这次的动静合不合适。

## 什么时候出卡片

卡片多半来自你的 Claude Code 和 Codex 会话：会话做完或停了，弹一个名字；需要你时出一张卡，带「允许」「拒绝」、一份计划或一个问题；会话做完又来问你一句时，也出一张卡。

把卡片放下（Esc、叉、横扫、点别处）不算回答。它绝不会被当成「拒绝」，也不会反复来催，只留在你的列表里。你正在 Claude 里干活时，她会把名字弹窗压住。

## 告诉她刚才吵不吵

每张卡片上有一行折起来的「合适吗」。点开可以确认这个级别合适，也可以选它本该有的级别：从只记一笔，到亮一下、出卡片、卡片带声，再到开口。确认你要求的事（比如确认卡）和你自己点开的页面，不问这个。

你的回答连同卡片的快照留在你自己的机器上：卡片的种类、标题、数量、工具名，以及当时的情形，比如安静档和钟点；代理写的话、命令和路径从不留。放着不管超过 30 分钟的卡片记为「忽略」。目前这些评价只是记录，不会自动学习：决定卡片级别的规则是固定的，日志的用处是将来拿更好的规则来对照。

## 把音量调低

安静档只有一个，由守护进程保管，所以刘海、提示音和她的声音是一致的，重启后也还在。每一档都包含上一档：

- **安静：**她不会主动开口，所有提示音关掉，卡片照常出现。
- **不弹：**再加上也不出卡片。Claude Code 的权限请求直接交给它自己的对话框，不会停在一张你看不见的卡片上。
- **勿扰：**再加上对外面的一切没有可见反应，连刘海旁的星星标记也停住。

用一句固定的话就能切换，中英文都行，不经过模型；也可以从她的右键菜单切。你自己设的提醒，任何一档都照响。

## 回来时看一条摘要

被压住的事一件不丢。你从「不弹」或「勿扰」出来时，攒下的会一起给你：只有一件，就是它本来的样子；多件就合成一张「你不在时有 N 件事」，要你处理的在前，其次出错，最后做完。

她看得出你在通话或不在座位时，同样会压住。这需要打开屏幕活动的读取；没打开，她就判断不了，也就什么都不压。

## 出声之前的检查

提示音要同时满足：安静档是正常、没有静音、不在通话或离开、输出是私密的（耳机一类，内置扬声器、USB 音箱和认不出的设备都不算）。她拿不准的时候，卡片照出，但不出声。她开口说话则更严：你不能正在和她对话，她也不能刚说过话。
