Jarvis 是一颗住在 MacBook 刘海旁边、长着两只眼睛的玻璃小球，其他一切都从这个位置长出来。她被设计成扫一眼就够：不用打开任何东西，也不会盖在你的工作上面。

## 她住在刘海里

平时她待在摄像头左边那一小块黑色延伸里，眨眼，看着你的鼠标。鼠标大约十分钟没动，她就打起瞌睡。没有刘海的屏幕上，她改住在顶部正中的黑色胶囊里，鼠标靠近之前不露面。

她只有一个。鼠标停到另一块屏幕上，她会先缩回当前屏幕的岛里，再从新屏幕的岛里冒出来。

## 跟她打招呼

悬停、轻戳、按住，各管一件事。把鼠标停在岛上她那一侧，她会探出头来看你；快速划过菜单栏则什么也不会发生，这是故意的。轻戳她一下，可以开始语音对话、在她说话时打断她，或者结束对话。连按两下左 ⌘ 键和戳她完全一样，适合手正放在键盘上的时候。

按住她一会儿，她会换装：深空玻璃、星云、银河、磨砂、极光，或者取自 App 图标的那一套。你不理她的时候，她每隔几分钟自己试一套。右键点她会出一个小菜单：她的样子、她说的话以多少文字显示、她该多安静，还有设置。

## 看刘海，知道谁在等你

刘海右侧是你的编程 agent 出现的地方。Claude Code 和 Codex 会话按状态归成几个小标记，每个带一个数字：等你、进行中、已完成、已搁置。鼠标停在上面，岛会向下长出一块面板，每个会话占一行。某个会话想运行命令时，刘海会掉下一张卡片，你不用切换窗口就能允许或拒绝。

在通知上横向轻扫就能收起它；把“已完成”的标记从菜单栏往下拖，所有做完的会话一次归档。你也可以直接告诉她少弹窗，或者完全别打扰你。

## 打开 Dashboard

Dashboard 是刘海的大号形态，扫一眼不够时用。点一下刘海，或者把鼠标停在上面，一块面板就从岛里直接长出来，她仍留在家里。里面有你和她的对话、今天的日程和待办、邮件、记忆、agents 和用量，底部还有一个可以给她打字的输入框。每一块都会原地展开成自己的页面，鼠标移开后面板自动收起。

想让它留着，就把标题往下拉，它会撕成一个独立窗口。

<!-- shot: 刘海下方展开的 Dashboard，示例数据：今天列表、一行邮件、一行 agents、“Ask Jarvis…”输入框 -->

## 让她让开

鼠标放在菜单栏里按住 ⌘，她会整个藏起来，方便你点到她下面的菜单栏图标。松手大约三秒后她回来。

想在配置之前先看看她，演示模式会用示例数据跑起整个界面和 Dashboard。它不听也不说话。
