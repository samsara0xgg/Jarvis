title: 记忆
description: Jarvis 把过去的每一天留成一份简短摘要，每晚把她对你的了解改写成一个可撤回的新版本，每条记忆都能追到出处、也能由你来改。
---

Jarvis 的记忆分两层：过去每一天的简短摘要，和一份关于你的长期笔记，后者由她在夜里修订。两层都是从完整的对话记录里派生出来的，你都可以查看、纠正。

## 每一天留下什么

每天一次，她会给每个还没有摘要的过去日子写一份。摘要分三块：聊了什么、你说定了什么、还有什么没做完。每一行都标着它所依据的那条记录。如果某天话很少，就原话保留，因为几行字的摘要并不比原文更短。

聊天时她能看到最近三天的摘要，加上从最新摘要的下一天起的每一句原话。更早的内容，需要时她再去查。这样提示词保持精简，而任何一天的原话仍然在对话记录里，记录本身从不被改写。

## 她对你的了解，是一个个版本

这份长期笔记有六栏：关于你、偏好、常提到的人、正在做的事、定下来的规矩、承诺和待办。它有长度上限（默认 4000 字），因为每次对话都要带上它，错一行，之后每一轮都要付出代价。

她从不原地修改它。每次改动都是一个新版本，不管是对话里她随手记下的，还是夜里整理加进去的，旧版本都保留着。夜里，模型会读每一个还没整理的日子，提出几种固定类型的改动：加一条、改写一条、或标为过时。每条改动都必须引用当天对话里的具体几句；只要有一项检查没过，整批就丢掉，再问一次。至于日期已经过去的待办，则由程序按日期直接标为过时，不经过模型。

结果是：她写下的关于你的任何内容都有据可查。没有引用的条目进不来，哪天整理得不好，也可以整个撤回。

## 检查和纠正一条记忆

Memory 页面按栏目列出所有条目，昨晚新记的放在最上面。点开一条，会看到它出自你们说过的哪几句，你可以对照原话判断它对不对。你可以点「对」确认、编辑、挪到别的栏目，或者删掉。也可以搜索说过的话，「改动」里列着每一个版本，每个都能撤回。

<!-- shot: Memory 页面，打开一条记忆，显示「出自这几句」的原话以及编辑、删除操作，示例数据 -->

这些操作本身也各是一个新版本，所以都能撤回。如果之后又有改动碰过同一条，撤回会被拒绝并指出是哪一条，而不是去猜你的意思。

## 为什么你改过的会被钉住

你编辑或挪动过的条目会被钉住。夜里的整理不会改写它，如果它看起来过时了，她只会留一条提醒，由你决定。点「对」确认一条并不会钉住它，之后它仍可以随情况更新。道理很简单：改了却在第二天夜里被悄悄覆盖，比没改还糟。
