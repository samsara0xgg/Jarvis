# 时间线分层约定（草案，2026-10-20）

原则：只看第一层，就能把今天讲出来。第二层是每一段里的零碎事和依据。

**第一版（10-20 和第二层对齐）**：列表每一行就是大脑「在干嘛」那条线（doing lane）的一段；地点、Mac 工作块、通话、照片、付款、日程、提醒这些原始记录，收进大脑标好的所属段，点开才看到；和她的对话完全不上时间线（聊天记录本来就在，只留顶上「和她」这个分类）；大脑不知道的段写「不知道在干嘛」；今天最近还没分好的一小截，先用原始记录顶着。下面「一段里分量够的事」「重要的瞬间」「照片缩略图」留到第二版。

## 总条（最上面那条）

- 默认按「在干嘛」分段，一种颜色对应一类事：工作、学习、吃饭、休息、娱乐、路上、运动、见人、睡觉、没记录。一件事持续 15 分钟以上才成一段，更短的并进相邻的段。
- 切到「位置」以后，换成现在这种按地点画的线。
- 点下面的分类，总条就换成这一类自己的切片：
  - 睡眠：深睡、浅睡、REM、醒着（现在就是这样）。
  - Mac：按 TimeSink 的分类切成写代码、浏览、视频、聊天等。现在整条都画成 Mac，这是错的。
  - 通话、和她：保持现在的样子。
- 一次性的事在总条上不画成很短的条，画成小圆点，点一下显示是什么。

## 第一层（列表里直接看到）

1. **段**：一段接一段铺满一天，和总条一一对应。每行写：时间、在干嘛、在哪、多久。门槛是 15 分钟。行尾用几个小图标加数字，提示这段里面有什么（比如照片 3、付款 1、通话 2），不点开也知道值不值得点。
2. **一段里分量够的事**：直接缩进显示在这段下面，不把这段拆断。分量够的标准：
   - 通话：3 分钟以上。
   - 运动：10 分钟以上。
3. **重要的瞬间**：不管多短都占一条细行。包括日程和会议、求职邮件（面试、offer）、你让她记住的事。
4. **照片**：不单独成行，以缩略图挂在拍照时所在的那一段上。
5. **现在以后**：日程、提醒、该出门。

最上面那排全天总数也算进没上列表的短事。

## 第二层（点开一段看到的）

| 这段是什么 | 点开看到 |
|---|---|
| 在 Mac 上工作 | 每个项目、每个 App 各用了多久（TimeSink 的切片），这段时间里 Claude Code 会话的标题 |

| 听 / 看了什么 | 哪个 App，主要的几首歌或几个视频，用的哪副耳机 |

| 手机使用 | 每个 App 各用了多久 |
| 日程、提醒 | 这段时间里的日程和提醒 |

## 后端要做的

1. 「在干嘛」那条线要拆成真正在做的事。现在的分类表里有「在家」，这是按地点分的，也是总条上只有睡眠和在家的原因之一。拆的时候用上 TimeSink 的 Away / Inactive、手机使用和手表的数据。
2. 每条原始记录标上它和哪几段重叠（第二层接了），比如字段 `doing: [段的 id, ...]`。一条记录跨好几段（比如在家一整天），就每段都列上，时长由界面按段截。层级字段先不要。
3. Mac 的切片：TimeSink 的原始数据已经在大脑上（ADR 0294），要按它的分类切好再发出来。
4. 通话尽量带上对方是谁。和她的聊天不上时间线，不用摘要。
